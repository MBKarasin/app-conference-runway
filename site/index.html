    How dates are checked

    Coverage note. International coverage is being expanded. This is still an incomplete global calendar; suggest a missing meeting or organizer.

    The source checker is scheduled for about 2 a.m. Eastern. Each record keeps its source status and review date:

    Start found
    The start date, its year and a distinctive meeting-name word were found on the organizer's page. The end date still needs confirmation.
    Source wording changed
    The start date was found, but the saved source excerpt no longer matches the page. Review the organizer's full date range.
    Needs review
    The page no longer shows them. Nothing changes until the curator reviews it.
    Organizer dates conflict
    The organizer publishes inconsistent dates. The listing carries a warning until the final range is resolved.
    Not re-checked
    The page can't be read automatically, so the date is shown as compiled.
    Recorded when published
    The meeting has ended. The date is kept as the organizer's page read at the time and is no longer re-checked, because organizers replace that page with the next edition.
    Save the date
    The organizer has announced the days, often on a flyer, but has not published a programme yet.
    Expected
    The meeting's usual month, projected up to three years ahead. Never given a day.
    Set by rule
    A celebration week or day computed from the organizer's published rule.

    Some organizers print their dates only inside a banner or flyer image, which the automatic check cannot read; those are confirmed by eye and the record links the image.

    Source checked dates is on by default. It includes automatic start-date checks with matching source wording, manually reviewed organizer dates, and observances set by published rules. It excludes date conflicts, missing or unreachable sources, and changed source wording. Switch it off to inspect those exceptions and expected months. Completed checks are archived so past meetings remain available.
